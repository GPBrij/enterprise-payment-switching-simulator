# Publication Boundary

## Publicly suitable

- High-level capability descriptions
- Two-dimensional Mermaid architecture views
- Synthetic demo scenarios
- Technology stack summary
- Release roadmap and Git tags
- Metadata definitions and control objectives
- Screenshots containing synthetic data only

## Keep private

- Real cardholder, customer, account or transaction data
- Live BIN data or institution routing tables
- PIN, CVV, track data, cryptographic keys or HSM procedures
- Credentials, environment variables and local configuration secrets
- Proprietary vendor documentation, message maps or configuration
- Confidential employer or client information
- Detailed security weaknesses or bypass instructions

## Intellectual-property statement

EPSS is an original demonstrator. Public documentation explains architecture, governance and outcomes without publishing proprietary commercial-switch implementation details or confidential banking information.
