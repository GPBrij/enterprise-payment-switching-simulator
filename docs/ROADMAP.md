# Release Roadmap

## Delivered

- v1.0 Foundation
- v1.1 Transaction Journal
- v1.2 Routing Engine
- v1.3 Issuer Simulator
- v1.4 Fraud Engine
- v1.5 Settlement Engine
- v1.6 Operations Dashboard and Management Reporting

## Candidate future increments

- ISO 8583 learning adapter using synthetic messages
- Reversal and timeout simulation
- Idempotency and duplicate-message controls
- Test automation and performance testing
- Observability with Prometheus and Grafana
- Role-based administration for demo configuration

Future items are design intentions, not current capabilities.
